# DPSPA FORKOM SISPALA Nganjuk

Website statis untuk GitHub Pages.

## Struktur utama
- `index.html` — halaman beranda
- `tentang.html` — profil
- `organisasi.html` — struktur organisasi
- `ad-art.html` — AD/ART
- `kegiatan.html` — program & kegiatan
- `berita.html` — berita
- `css/style.css` — seluruh styling
- `js/script.js` — navigasi mobile, animasi, dan lightbox
- `images/` — logo, hero, foto kegiatan, galeri
- `documents/` — AD, ART, dan dokumen publik lain

## Cara pakai
1. Ganti file contoh di `images/` dengan foto/logo asli menggunakan nama file yang sama.
2. Masukkan `ad.pdf` dan `art.pdf` final ke folder `documents/`.
3. Edit teks/kontak di `index.html` sesuai data resmi.
4. Upload seluruh isi folder ini ke repository GitHub.
5. Aktifkan GitHub Pages dari Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Jangan masukkan data pribadi atau dokumen internal yang tidak dimaksudkan untuk publik.
